# Item 23 — moments

Migration **`0017`** (pre-allocated; it moved down from `0013` and then from
`0015` so the non-GUI wave could land ahead of it). Depends on item 21's
`reading_events` (`0011`). **Engine and API only** — no CLI, no TUI, nothing
under `gui/` except the regenerated `bindings.ts`.

## What it is

A moment fires once. That requires knowing it fired, which is state the app
keeps about **itself** and never a number shown to anyone.

Derive candidate moments from what already happened:

- a reading closed;
- a first annotation on a book that carried none;
- a reflection that reached a book it had not reached before;
- a run of activity days that ended.

Record which have been surfaced, so the ceremony does not replay on every
launch.

## What it must not do

- **Nothing is a threshold announced in advance, and nothing counts down.** A
  moment is recognised retrospectively or it is a target wearing a costume.
  `docs/decisions.md` forbids task-completion framing by name.
- **No count, anywhere on the wire.** Not a total, not a "pending", not a count
  endpoint reached for on grounds of cheapness. The length of the list is the
  frontend's business; a number waiting is a badge.
- **No push channel.** This protocol has none, and a moment stream would reopen
  the argument the mount watcher was deliberately left outside the vocabulary to
  avoid. A client polls.
- **An import mints nothing.** A fresh install importing a 400-book Goodreads
  CSV must not mint 400 moments: a moment fires only for events occurring
  **after** the book is in the library, because an import is history arriving
  rather than a thing you just did. Cards are still minted for all 400 — the
  shelf is the history — and cards are item 28's.

## What item 28 needs from the wire

Named by an API audit before this was built, and treated as requirements:

- a poll-able `PendingMoments` returning a list of moments;
- **`reading_id` on the moment, not only `book_id`** — a card is minted per
  *reading* and a reread mints a second beside the first, so a moment
  identified by its book cannot select the right card. The expensive one to add
  later, because it changes what a moment *is*;
- an acknowledge write, and a statement about whether it is idempotent;
- no count.
